# Enemy Randomizer RMM Bridge

The bridge makes Matt's enemy randomizer `Launch DS1` path use the selected dedicated `DRAKS0005.rmm`. It does not move or patch the enemy-randomizer executable.

## Current layout

- Keep `DS1EnemyRandomizer.exe` in its existing self-contained folder.
- Keep `Select exe` pointed at the active copied runtime's `DarkSoulsRemastered.exe`.
- Bridge artifacts are deployed to `D:\DSR MOD\components\rmm-bridge`.
- The selected profile resolves to `D:\DSR MOD\saves\<SteamID>\DRAKS0005.rmm`.

## Regeneration

`config_randomizer.toml` is generated by the enemy randomizer and can be overwritten by `Randomize!`. The current UI is configured with `D:\DSR MOD\components\rmm-bridge` as the additional mod directory and `DSRRandomizer.RmmBridge.dll` as an extra DLL. Keep both `Use crash fix dll` and `Merge files from game directory` enabled so `DS1HeapPatch.dll` loads early and item-randomizer files from the copied runtime are preserved in regenerated output.

After every regeneration, verify before launch:

```powershell
& .\scripts\publish-rmm-bridge.ps1 -ExternalRoot 'D:\DSR MOD' -VerifyOnly
```

Verification requires `DSRRandomizer.RmmBridge.dll` and `DS1HeapPatch.dll` in `external_dlls` and rejects `DarkSoulsItemRandomizer.exe` there. The item-randomizer executable is a generator, not a loadable DLL.

## Launch and rollback

Put Steam in Offline Mode, close existing game/bridge-host processes, and press `Launch DS1`. A bridge/bootstrap failure terminates the copied game and records `D:\DSR MOD\logs\rmm-bridge.log`; it never falls back to a normal `.sl2`.

To roll back, remove the bridge directory from the enemy-randomizer DLL-mod selection and run `Randomize!` again. Confirm `config_randomizer.toml` no longer mentions `DSRRandomizer.RmmBridge.dll`. Existing bridge artifacts may remain inert under `components\rmm-bridge`.
